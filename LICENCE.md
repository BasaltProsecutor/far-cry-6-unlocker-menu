## 🧩 About

**Far Cry 6 Companion** is a curated list of Far Cry 6 open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot overlay, map overlay
- **Quality-of-Life Helpers** — loadout catalog, resource notes, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Mission Helpers
- Checkpoint Notes — practice from any mission segment
- Map Overlay — visualize points of interest and collectibles
- Loot overlay — track resources and supply drops
- Playback Notes — review recorded runs for study

### 🎨 Catalog & Loadout
- Weapon Catalog — browse weapons, mods, and ammo types
- Outfit Notes — organize gear and cosmetic sets
- HUD Overlay — improved visibility for resources and ammo

### 🏋️ Practice Layout
- Stealth Notes — segment study on any outpost layout
- Fast Travel Notes — plan routes between safehouses
- Vehicle Notes — organize handling and tuning notes
